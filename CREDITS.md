## Credit travels with the files

Each JPEG carries the same credit in an embedded comment segment, so the
attribution survives being copied out of this repository. Read it back with:

```bash
magick identify -verbose backgrounds/01-pukaki-road.jpg | grep comment
```

The comment was inserted without re-encoding, so the image data is bit-for-bit
what the photographer uploaded.
