## A note on resolution

Every background is 3840px wide or larger, with one deliberate exception:
`04-tekapo-lupins.jpg` is 3790px, fifty pixels short. It is included at its
native size rather than upscaled, and on a 3840-wide display the compositor
stretches it by 1.3%, which is not visible. It earns the place.

## Credit travels with the files

Each JPEG carries the same credit in an embedded comment segment, so the
attribution survives being copied out of this repository. Read it back with:

```bash
magick identify -verbose backgrounds/01-pukaki-swimmers.jpg | grep comment
```

The comment was inserted without re-encoding, so the image data is bit-for-bit
what the photographer uploaded.
